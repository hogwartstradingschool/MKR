# MKR
Offline video player + built-in Video Grabber (Android 6.0+).

**Grabber kaise use karein**
1. Kisi bhi app mein video ka link Share karo -> **MKR Player** chuno, ya link copy karke MKR kholo -> **GRABBER** tab -> PASTE.
2. Quality wala popup khulega -> quality tap karo -> download shuru.
3. Video `Movies/VideoGrabber` mein save hoti hai aur MKR ki VIDEOS list mein foran aa jati hai.

GitHub par push karo -> Actions tab -> "Build APK" -> Artifacts mein MKR-APK download karo.
(Build: JDK 17, Gradle 8.9.)

Alag app hai (id: com.mkr.app) - purani MKR Player ke upar install nahi hoti, dono saath rahengi.
